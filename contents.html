class gbsdr.Graph(nodal_coords, edges, weights=None)

Bases: object

Initialize the representation of a graph.

Parameters:

  • nodal_coords (array-like of shape (n_nodes, n_dims)) – Coordinates of each node in the structure. Each row corresponds to a node and contains its spatial coordinates.

  • edges (array-like or list of lists) – List of edges in the graph. Each edge is represented as a pair of node indices.

  • weights (array-like) – Edge weights representing axial forces.

Notes

This initializer constructs the full graph representation of a structural system, including geometry, topology, and optionally applied loads and boundary conditions.

property ClosenessCentrality

Closeness centrality of the graph.

Closeness centrality measures how close a node is to all other nodes in the graph based on shortest path distances. Nodes with higher values can reach all other nodes more quickly on average.

Higher values indicate nodes that are more centrally located in terms of graph distance.

Returns:

Return type:

Notes

Computed using NetworkX closeness centrality. See: https://en.wikipedia.org/wiki/Closeness_centrality.

Degree centrality of the graph.

Degree centrality measures the fraction of nodes a given node is directly connected to. It is the simplest form of centrality and reflects immediate connectivity in the network.

Nodes with high degree centrality are directly connected to many other nodes.

property Density

Graph density.

Graph density measures how close the graph is to being complete, defined as the ratio of existing edges to the maximum possible number of edges.

  • Density = 0 → no edges in the graph

  • Density = 1 → fully connected (complete graph)

  • Intermediate values indicate how sparsely or densely connected the graph is

Returns:

Graph density in the range [0, 1].

Return type:

float

Notes

Computed using NetworkX. See: https://networkx.org/documentation/stable/reference/generated/networkx.density.html

property Diameter

Graph diameter.

The diameter of a graph is the longest shortest-path distance between any pair of nodes. It represents the greatest minimal distance required to travel between two nodes in the network.

  • The diameter represents the worst-case shortest-path distance in the graph.

  • It provides a measure of the “size” of the graph in terms of connectivity.

  • Larger values indicate more spread-out or less tightly connected graphs.

Returns:

Diameter of the graph.

Return type:

float

Notes

Computed using NetworkX. See: https://en.wikipedia.org/wiki/Diameter_(graph_theory).

Warning

The graph must be connected. For disconnected graphs, NetworkX raises an exception unless a different definition (e.g. per component) is used.

property FiedlerVec

Fiedler value and Fiedler vector of the graph Laplacian.

The Fiedler value is the second smallest eigenvalue of the graph Laplacian, and the corresponding eigenvector is the Fiedler vector. These are commonly used in spectral graph theory to analyze graph connectivity and partitioning.

  • The Fiedler value (algebraic connectivity) indicates how well connected the graph is. Larger values imply stronger connectivity.

  • The Fiedler vector can be used for graph partitioning and clustering.

Returns:

float

Second smallest eigenvalue of the Laplacian matrix.

numpy.ndarray

Eigenvector corresponding to the Fiedler value.

Return type:

tuple of (float, numpy.ndarray)

Notes

Computed from the combinatorial Laplacian matrix using SciPy. See: https://en.wikipedia.org/wiki/Algebraic_connectivity.

Warning

Eigenvalues are not explicitly sorted. This implementation assumes that the second entry corresponds to the Fiedler value, which may not be correct in all cases. Eigenvalues should be sorted before selecting the Fiedler value.

property GlobalClusteringCoefficient

Global clustering coefficient of the graph.

The global clustering coefficient (also called transitivity) measures the fraction of closed triplets (triangles) over all connected triplets of nodes in the graph.

  • Value = 1 → every triplet is closed (maximal clustering, e.g., complete graph)

  • Value = 0 → no closed triplets (no clustering)

  • Intermediate values indicate the tendency of nodes to form triangles

Returns:

Global clustering coefficient in the range [0, 1].

Return type:

float

Notes

  • A triplet consists of three nodes connected by at least two edges.

  • Computed as: 3 × (number of triangles) / (number of connected triplets).

  • Returns 0.0 if the graph contains no triplets.

  • Useful for identifying critical nodes in communication, transport, or structural vulnerability analysis.

BracedVariants()

Generate all possible braced graph variants by combining face triangulations.

For each face in the graph, all possible triangulation scenarios are computed. A Cartesian product of these scenarios is then used to generate all global bracing combinations. Each combination produces a new graph variant with additional bracing edges.

Returns:

List of fully braced graph variants.

Return type:

list of Graph

Notes

  • Each face contributes a set of possible triangulation scenarios.

  • A global variant is created by selecting one scenario per face.

  • Newly added bracing edges are initialized with zero axial force.

  • Deep copies are used to avoid modifying the original graph state.

  • Requires itertools and copy.

LaplacianMatrix(normalized: bool = False, numpy: bool = False)

Return the Laplacian matrix of the graph.

The Laplacian matrix is a key operator in spectral graph theory.

  • Unnormalized (combinatorial Laplacian): L = D - A

  • Normalized Laplacian:

    L = I - D^{-1/2} A D^{-1/2}

Normalized Laplacians reduce degree bias and are widely used in spectral methods and graph neural networks.

See: https://en.wikipedia.org/wiki/Laplacian_matrix.

Parameters:

  • normalized (bool, optional) – If True, compute the normalized Laplacian. Default is False.

  • numpy (bool, optional) – If True, return result as a NumPy array. If False, return as a nested Python list. Default is False.

Returns:

static DeterminacyCheck(truss: Truss, BC: list[str], rtol=1e-09) → dict[str, int]

Count states of self-stress and mechanisms of a supported truss.

Assemble the equilibrium matrix of the members, delete the rows of the restrained degrees of freedom, compute the numerical rank of the reduced matrix from its singular values, and derive the number of independent states of self-stress and of inextensional mechanisms.

Parameters:

  • truss (Truss or Graph) – Pin-jointed truss with node coordinates, members, and support nodes (truss.SupportNodeIds). The number of degrees of freedom per node is read from truss.DOFperNode (Truss) or inferred from truss.Vertices by Vector.VecPlanarization (Graph).

  • BC (list of str) – Support type of each node in truss.SupportNodeIds, in the same order, as accepted by StructuralAnalysisUtils.BuildSupports.

  • rtol (float, optional) – Intended relative tolerance for the rank. Currently unused: the rank is computed with the default tolerance of np.linalg.matrix_rank (see Notes). Default is 1e-9.

Returns:

result – With the keys

  • "s": number of independent states of self-stress.

  • "m": number of independent inextensional mechanisms, including rigid-body motions not prevented by the supports.

  • "r": rank of the reduced equilibrium matrix.

Return type:

dict of {str: int}

Raises:

ValueError – If the number of degrees of freedom per node is not 2 or 3.

Notes

Let \(B\) be the equilibrium matrix of the \(b\) members, of shape \((d j, b)\) for \(j\) nodes in \(d\) dimensions, with one row per nodal degree of freedom and one column per member, so that \(B t = f\) for member forces \(t\) and nodal loads \(f\). Deleting the rows of the \(c\) restrained degrees of freedom gives the reduced matrix \(B_r\), of shape \((d j - c, b)\), and

\[r = \operatorname{rank}(B_r), \qquad s = b - r, \qquad m = d j - c - r,\]

the dimensions of the null spaces of \(B_r\) and \(B_r^{\mathsf{T}}\) (Pellegrino and Calladine, 1986). They satisfy the extended Maxwell rule \(s - m = b + c - d j\) (Calladine, 1978). The truss is statically determinate if \(s = 0\) and kinematically determinate if \(m = 0\).

Deleting the rows is equivalent to appending one unit reaction column per restrained degree of freedom to \(B\): the extended matrix has rank \(r + c\) and gives the same \(s\) and \(m\).

StructuralAnalysisUtils.GlobalEquilibriumMatrix is assumed to order the rows of \(B\) in the same way as StructuralAnalysisUtils.GetSupportDOF numbers the degrees of freedom. Supports restrain displacements along the global axes, and \(c\) counts distinct restrained degrees of freedom, since np.delete removes a row listed twice only once.

A singular value of \(B_r\) counts as nonzero if it exceeds \(\sigma_{\max} \max(d j - c, b)\, \varepsilon\), with \(\sigma_{\max}\) the largest singular value and \(\varepsilon\) the float64 machine epsilon, which is the default tolerance of np.linalg.matrix_rank.

The analysis is linear: \(m\) counts first-order (infinitesimal) mechanisms and does not distinguish finite mechanisms from mechanisms stabilized by a state of self-stress.

References

C. R. Calladine, “Buckminster Fuller’s ‘tensegrity’ structures and Clerk Maxwell’s rules for the construction of stiff frames,” International Journal of Solids and Structures, vol. 14, no. 2, pp. 161–172, 1978.

S. Pellegrino and C. R. Calladine, “Matrix analysis of statically and kinematically indeterminate frameworks,” International Journal of Solids and Structures, vol. 22, no. 4, pp. 409–428, 1986.

Assemble the global equilibrium matrix of a pin-jointed truss.

Each column belongs to a member and each row to one nodal degree of freedom. The column of a member holds its unit vector, from its start node to its end node, with a positive sign at the start node and a negative sign at the end node.

Parameters:

truss (Truss or Graph) – Truss with node coordinates (truss.Coords2D, shape (n, 2), if planar; truss.Vertices, shape (n, 3), if spatial), member connectivity (truss.EdgeNodePairs, shape (m, 2), start and end node indices), number of nodes n (truss.Order), and number of members m (truss.Size). The number of degrees of freedom per node d is read from truss.DOFperNode (Truss) or inferred from truss.Vertices by Vector.VecPlanarization (Graph).

Returns:

B – Global equilibrium matrix, shape (d n, m), with d = 2 or 3. Row d i + k is the equilibrium of node i along axis k. Supports are not included: all nodes have d rows.

Return type:

ndarray

Raises:

ValueError – If d is not 2 or 3, or if the coordinates do not have d components.

Notes

  • For member \(e\) from node \(i\) to node \(j\), with unit vector \(\mathbf{e}_e = (\mathbf{x}_j - \mathbf{x}_i) / L_e\), the only nonzero entries of column \(e\) are

    \[B_{d i + k, \, e} = e_{e,k}, \qquad B_{d j + k, \, e} = -e_{e,k}, \qquad k = 0, \dots, d - 1,\]

    i.e., the direction cosines \((c, s)\) in 2D and \((l, m, n)\) in 3D. For example, a 2D member from node 0 at (0, 0) to node 2 at (3, 4) has \(L = 5\), \(c = 0.6\), and \(s = 0.8\); its column holds 0.6 and 0.8 in rows 0 and 1, and -0.6 and -0.8 in rows 4 and 5.

  • With tension-positive axial forces \(\mathbf{t}\), external nodal loads \(\mathbf{p}\), and nodal displacements \(\mathbf{u}\), equilibrium and compatibility read

    \[B \, \mathbf{t} + \mathbf{p} = \mathbf{0}, \qquad \boldsymbol{\delta} = -B^{\mathsf{T}} \mathbf{u},\]

    where \(\boldsymbol{\delta}\) are the member elongations. Hence the compatibility matrix is \(C = -B^{\mathsf{T}}\), and \(B \, \mathbf{q} = \mathbf{p}\) for compression-positive forces \(\mathbf{q}\).

  • States of self-stress span the null space of \(B\), and inextensional displacements, including rigid-body motions, span the null space of \(B^{\mathsf{T}}\) [2]. The same matrix appears in the plastic ground-structure formulation of layout optimization [1].

  • The linear stiffness matrix \(K = B \operatorname{diag}(EA/L) \, B^{\mathsf{T}}\) does not depend on the sign convention.

  • Members carry axial force only, and equilibrium is written in the undeformed geometry (small displacements).

  • Node indices in truss.EdgeNodePairs run from 0 to n - 1 and match the rows of the coordinate arrays.

  • For planar trusses, truss.Coords2D must hold coordinates in the plane of the truss, not a projection onto XY; otherwise trusses in other planes (e.g., XZ) give incorrect matrices.

  • Zero-length members are not checked: they give NaN entries and a NumPy runtime warning, not an error.

References

[1]

W. S. Dorn, R. E. Gomory, and H. J. Greenberg, “Automatic design of optimal structures,” Journal de Mécanique, vol. 3, pp. 25–52, 1964.

[2]

S. Pellegrino and C. R. Calladine, “Matrix analysis of statically and kinematically indeterminate frameworks,” International Journal of Solids and Structures, vol. 22, no. 4, pp. 409–428, 1986.

static SolveTrussLayoutOptimization(gs: GroundStructure, support_node_ids: list[int], load_node_ids: list[int], load_components: list[tuple], ratio_tc=1.0, plot_summary=True)

Find the minimum-volume truss in a ground structure by linear programming.

Solve the plastic layout optimization problem for a single load case over all candidate members of gs, keep the members with nonzero force, recover the support reactions, and return the reduced structure with renumbered nodes.

Parameters:

  • gs (GroundStructure) – Ground structure. Uses gs.graph, with Vertices, Order (number of nodes n), Size (number of candidate members m), Lengths, and AdjacencyList.

  • support_node_ids (list of int) – Indices of the support nodes in gs.graph. All DOFs of these nodes are fixed (pinned supports).

  • load_node_ids (list of int) – Indices of the loaded nodes in gs.graph.

  • load_components (list of tuple of float) – Load vector at each node in load_node_ids, in the same order, in force units (e.g., kN), as accepted by StructuralAnalysisUtils.GlobalForceVectorGraph.

  • ratio_tc (float, optional) – Ratio of compressive to tensile stress limit, \(\sigma_c = \mathrm{ratio\_tc} \cdot \sigma_t\). Values below 1 penalize compression. Must be positive. Default is 1.0.

  • plot_summary (bool, optional) – If True, print the solver status, objective value, equilibrium residual norm, and active members. Nothing is plotted. Default is True.

Returns:

structure – Optimized structure with the active members only, nodes renumbered \(0, \dots, k - 1\) in increasing order of their original indices, and member weights equal to the signed axial forces (positive = tension), in force units. A Truss also holds the loads, the support reactions (as additional nodal forces), and the supports. If building the Truss raises any exception, a Graph with geometry, connectivity, and forces is returned instead, without warning.

Return type:

Truss or Graph

Raises:

  • ValueError – If the detected dimension is not 2 or 3, or if linprog returns no solution vector (e.g., an infeasible problem).

  • KeyError – If a load or support node is not connected to any active member in the optimal layout.

Notes

  • Plastic formulation (Dorn, Gomory, and Greenberg, 1964, Journal de Mecanique 3:25-52; see also Gilbert and Tyas, 2003, Engineering Computations 20(8):1044-1064). With member forces \(\mathbf{q} = \mathbf{q}^+ - \mathbf{q}^-\):

    \[\begin{split}\begin{aligned} \min_{\mathbf{q}^+, \, \mathbf{q}^-} \quad & \sum_i \ell_i \left( \frac{q_i^+}{\sigma_t} + \frac{q_i^-}{\sigma_c} \right) \\ \text{s.t.} \quad & \mathbf{B} \left( \mathbf{q}^+ - \mathbf{q}^- \right) = -\mathbf{f}, \\ & \mathbf{q}^+ \geq \mathbf{0}, \quad \mathbf{q}^- \geq \mathbf{0}, \end{aligned}\end{split}\]

    where \(\mathbf{B}\) is the equilibrium matrix and \(\mathbf{f}\) the load vector, both restricted to the free DOFs. Solved with HiGHS via scipy.optimize.linprog.

  • \(\sigma_t = 1\), so the objective value equals the volume times \(\sigma_t\), i.e., \(\sum_i \ell_i |q_i|\) with compression weighted by \(1 / \mathrm{ratio\_tc}\), in force times length.

  • A single load case is considered. Compatibility is not enforced, so the result is a plastic (lower-bound) design, not a linear elastic one.

  • The dimension (2 or 3) and the plane are detected from the nodal coordinates with Vector.VecPlanarization.

  • Support reactions are recovered from the equilibrium residual of the full system, \(\mathbf{R} = -(\mathbf{B}_{\mathrm{full}} \mathbf{q} + \mathbf{f}_{\mathrm{full}})\), at the support DOFs.

  • Members are kept if \(|q_i| >\) Geometry.Tolerance. The tolerance is absolute and in force units, so it depends on the load magnitude.

  • The member areas \(a_i = |q_i| / \sigma\) (with \(\sigma = \sigma_t\) or \(\sigma_c\)) are computed but not returned.

  • result.success is not checked; only a missing solution vector raises an error.

Assemble the compatibility matrix of a truss from its geometry.

Build the matrix that maps nodal displacements to first-order member elongations, \(\mathbf{e} = \mathbf{R} \mathbf{u}\). Its transpose is the equilibrium matrix, \(\mathbf{R}^T \mathbf{N} = \mathbf{f}\), for member forces \(\mathbf{N}\) and nodal loads \(\mathbf{f}\).

Parameters:

truss (Truss) – Truss graph. Uses Coords2D, DOFperNode (dof), Order (number of nodes n), Size (number of members m), and EdgeNodePairs, a sequence of (i, j) node index pairs.

Returns:

R – Compatibility matrix (dimensionless). Row k corresponds to member k in the order of truss.EdgeNodePairs; columns follow the global DOF numbering dof * node + component.

Return type:

ndarray, shape (m, dof * n)

Raises:

ValueError – If a member has exactly zero length.

Notes

  • For member \(k = (i, j)\) with unit vector \(\hat{\mathbf{n}}_{ij} = (\mathbf{x}_i - \mathbf{x}_j) / L\), row \(k\) holds \(\hat{\mathbf{n}}_{ij}^T\) in the columns of node \(i\) and \(-\hat{\mathbf{n}}_{ij}^T\) in the columns of node \(j\). Then

    \[e_k = \frac{(\mathbf{u}_j - \mathbf{u}_i) \cdot (\mathbf{x}_j - \mathbf{x}_i)}{L},\]

    so positive elongations and positive (tensile) forces satisfy \(\mathbf{e} = \mathbf{R} \mathbf{u}\) and \(\mathbf{R}^T \mathbf{N} = \mathbf{f}\), consistent with the sign convention of the member force recovery.

  • truss.Coords2D must have dof columns: the two in-plane components for planar trusses or (x, y, z) for spatial trusses.

The null space of \(\mathbf{R}\) contains the rigid-body motions and inextensional mechanisms; the null space of \(\mathbf{R}^T\) contains the states of self-stress (Pellegrino and Calladine, 1986, Int. J. Solids Struct. 22(4):409-428).

  • In rigidity theory, the rigidity matrix is often defined with the unnormalized vectors \(\mathbf{x}_i - \mathbf{x}_j\) (e.g., Asimow and Roth, 1978, Trans. Amer. Math. Soc. 245:279-289). This version is row-scaled by \(1/L\), which leaves the rank and null space unchanged.

For each member, select the first area in cross_sections whose axial stress \(|F| / A\) does not exceed the allowable stress, then sum \(A L\) over all members.

Parameters:

static TributaryForces(coords: list[list[float]], node_ids: list[int], load_per_meter: float) → dict[int, float]

Lump a uniform line load onto the interior nodes of a loaded chord.

Convert a uniformly distributed load along an ordered chain of nodes into nodal point loads using tributary lengths measured along x. The two end nodes (supports) receive no load; their half-segment shares are added to the adjacent interior nodes.

Parameters:

  • coords (list of list of float, shape (n, >= 1)) – Nodal coordinates in length units (e.g., m). Only the first component, coords[k][0], is used.

  • node_ids (list of int, length p) – Indices into coords of the loaded nodes, ordered along the chord and including the two end (support) nodes.

  • load_per_meter (float) – Load intensity per unit length projected on the x-axis (e.g., kN/m).

Returns:

forces – Nodal load magnitude for each interior node in node_ids (e.g., kN). End nodes are not included. Empty if p < 3.

Return type:

dict of {int: float}

Notes

  • Tributary lengths use the projected distances \(|x_a - x_b|\), which is appropriate for loads per horizontal length (e.g., snow or floor loads), not for loads per chord length on sloped chords. The x-axis is used regardless of the analysis plane.

  • With \(\ell_k^-\) and \(\ell_k^+\) the projected lengths of the segments to the left and right of node \(k\), and load intensity \(q\), the nodal loads are

    \[\begin{split}P_k = \begin{cases} q \left(\ell_k^- + \tfrac{1}{2} \ell_k^+\right) & \text{first interior node}, \\ q \left(\tfrac{1}{2} \ell_k^- + \ell_k^+\right) & \text{last interior node}, \\ \tfrac{1}{2} q \left(\ell_k^- + \ell_k^+\right) & \text{otherwise}. \end{cases}\end{split}\]

    For \(p \geq 4\), the loads sum to \(q\) times the total projected length.

  • Moving the end-segment shares from the supports to interior nodes leaves the total reactions unchanged but increases the load carried through the members.

  • For \(p = 3\), only the first-interior-node rule is applied, so the load \(\tfrac{1}{2} q \ell_k^+\) is lost.

  • Returned values are magnitudes; the load direction and sign are applied by the caller.

Examples

>>> FE.TributaryForces(coords, [0, 1, 2, 3, 4], load_per_meter=5.0)

static Solver(graph, force_node_ids, ext_forces, fixed_node_ids, q)

Find the equilibrium geometry of a network by the force density method.

Given a force density for each member, solve the linear equilibrium equations of the free nodes for their coordinates, then compute the member lengths and axial forces (Schek, 1974).

Parameters:

  • graph (Graph) – Network with node coordinates (graph.VertexObjs, each with X, Y, Z), number of nodes (graph.Order), member connectivity (graph.EdgeNodePairs), and member-node incidence matrix (graph.Incidence, shape (m, n_nodes)). Only the coordinates of the fixed nodes are used.

  • force_node_ids (list of int) – Indices of the loaded nodes.

  • ext_forces (list of list of float) – External loads [[Fx, Fy, Fz], ...], in kN, one per entry of force_node_ids. Loads on fixed nodes are ignored.

  • fixed_node_ids (list of int) – Indices of the fixed (support) nodes, whose coordinates are prescribed. Must be a list (it is concatenated with other lists) with at least one entry and no duplicates.

  • q (array_like of float) – Force densities \(q_j = s_j / l_j\), in kN/m, shape (m,), in the row order of graph.Incidence. Positive values give tension.

Returns:

  • graph_ (Graph) – New network with the equilibrium coordinates, the member forces, the fixed nodes, and the loads.

  • axial_forces (ndarray) – Member axial forces \(s\), in kN, shape (m,), tension positive.

  • coords_ (ndarray) – Equilibrium node coordinates, in m, shape (n_nodes, 3), in the original node order.

Raises:

numpy.linalg.LinAlgError – If the stiffness-like matrix \(D\) is singular, e.g., when a part of the network is not connected to a fixed node.

Notes

  • With the incidence matrix split into free and fixed columns, \(C_s = [C \;\; C_f]\), and \(Q = \operatorname{diag}(q)\), the free coordinates solve

    \[D \, x = p_x - D_f \, x_f, \qquad D = C^{\mathsf{T}} Q \, C, \qquad D_f = C^{\mathsf{T}} Q \, C_f,\]

    and likewise for \(y\) and \(z\), where \(p_x\) holds the load components at the free nodes in the global axes.

  • The member forces are

    \[s_j = q_j \, l_j, \qquad l_j = \sqrt{u_j^2 + v_j^2 + w_j^2}, \qquad u = C x + C_f x_f,\]

    with \(v\) and \(w\) defined likewise.

  • The method has no material law: the geometry is the equilibrium shape for the given force densities, and the member lengths are a result. Unstressed lengths and elastic deformation are not computed.

  • For \(q_j > 0\) and every free node connected to a fixed node, \(D\) is symmetric positive definite. Negative force densities (compression) are allowed but may make \(D\) singular.

  • Units must be consistent; the units above assume kN and m.

References

H.-J. Schek, “The force density method for form finding and computation of general networks,” Computer Methods in Applied Mechanics and Engineering, vol. 3, no. 1, pp. 115–134, 1974.

The static action is written as a tuple, e.g., (11, 3), instead of a value rounded to 3 decimals. Each bar is one stock member; its height is the member length and its width scales with the cross-sectional area. Bars are grouped by profile (sorted by area), and profiles by type (shaded bands, labeled with the family). Within a profile, members are sorted by decreasing length.

A row below the bars shows each profile’s cross-section, filled and drawn to one common scale, so the filled areas are proportional to A. Sections without dimensions (synthetic stocks) are drawn as squares of area proportional to A.

  • group_gap (float, optional) – Spacing between profile groups.

  • font_scale (float, optional) – Scaling factor for all font sizes.

Visualize a ground-structure grid in 2D.

This method generates a 2D plot of a discretized ground structure, including nodes, connectivity (edges), and optional annotations such as node IDs and edge IDs. It is primarily used for inspection and debugging of structural layouts before analysis or optimization.

The visualization is based on a regular node grid defined by the ground structure object and supports flexible display options for different levels of detail.

Parameters:

  • fig_width (float, optional) – Width of the figure in inches. If None, derived from grid size.

  • fig_height (float, optional) – Height of the figure in inches. If None, derived from grid size.

  • font_scale (float, optional) – Scaling factor for all text elements (titles, labels, annotations).

  • node_scale (float, optional) – Scaling factor for node marker size.

  • node_font_scale (float, optional) – Scaling factor for node ID font size.

  • show_nodes (bool, optional) – If True, plots structural nodes.

  • show_edges (bool, optional) – If True, plots structural connectivity (edges).

  • show_node_ids (bool, optional) – If True, displays node indices next to nodes.

  • show_edge_ids (bool, optional) – If True, displays edge indices at midpoints of members.

  • show_supports (bool, optional) – Placeholder flag for future visualization of boundary conditions.

  • show_loads (bool, optional) – Placeholder flag for future visualization of external loads.

Plot the node grid of a ground structure with support and load nodes.

Draw all nodes in the x-y plane with their indices, highlight the support and load nodes, and show the figure.

Parameters:

  • ground_structure (GroundStructure) – Ground structure. Uses coords (shape (n, >= 2)), n_rows, n_cols, dx, and dy.

  • support_nodes (list of int, optional) – Indices of the support nodes, drawn as red squares. Default is None (none highlighted).

  • anchored_nodes (list of int, optional) – Indices of the loaded nodes, drawn as green X markers labeled “Load anchorage nodes”. Default is None (none highlighted).

  • fig_width (float, optional) – Figure width in inches. Default is None, which uses n_cols.

  • fig_height (float, optional) – Figure height in inches. Default is None, which uses n_rows.

  • show_legend (bool, optional) – If True, show a legend below the axes. Default is True.

  • font_scale (float, optional) – Scale factor for the title, axis labels, and legend text. Default is 1.

  • node_scale (float, optional) – Scale factor for the marker sizes. Default is 1.

  • node_font_scale (float, optional) – Scale factor for the node index labels. Default is 1.

Notes

  • Only the x and y coordinates are plotted. For spatial grids (depth > 1), nodes of different layers overlap, and the title shows only n_rows x n_cols.

  • Columns run along x and rows along y. Axis limits and ticks assume the grid starts at the origin, with spacings dx and dy.

  • Label offsets (0.04) and axis margins (-0.2, +0.4) are in coordinate units, so they are sized for spacings near 1.

  • Node labels are the row indices of coords.

  • A node in both lists shows the load marker on top of the support marker.

  • Calls plt.show(), which may block in scripts. The figure is not returned, so it cannot be saved or modified by the caller.
